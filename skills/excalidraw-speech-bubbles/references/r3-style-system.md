# R3 漫画吹き出し仕様

## 参照した動画

- https://www.youtube.com/watch?v=awAbZyTeE4g
- https://www.youtube.com/watch?v=2ycRncs4CKY

この仕様は、上記2本で共通して見られる吹き出しの視覚文法を抽出したもの。画像や固有セリフを再利用せず、形、余白、色、読み順だけを再現する。

## 視覚文法

- 漫画パネル上へ白い吹き出しを直接重ねる
- 本体は縦長の楕円、塗りは白、輪郭は黒
- セリフは太く見えるゴシック系の縦書き
- 通常文は黒。感情や話者識別に赤、青、マゼンタを使う
- 短い驚きは小さなトゲ付き吹き出しまたは小円
- 状況説明は尻尾のない白い縦帯
- 顔を避け、人物間やパネル端の空白へ置く
- 尻尾は短く、誰の発話か一目で分かる方向へ向ける

## 基準座標

以下は1920×1080の漫画画像を基準にした値。対象画像が `W × H` の場合は、次の倍率を使う。

`S = min(W / 1920, H / 1080)`

線幅や文字が小さくなりすぎる場合は最小値を優先する。

## 共通スタイル

| 項目 | R3標準 |
| --- | --- |
| 塗り | `#FFFFFF`, solid, opacity 96〜100 |
| 輪郭 | `#111111`, solid |
| 線幅 | `max(2, 4 × S)` |
| roughness | 0〜0.4。手描き感より読みやすさを優先 |
| 通常文字 | `#111111` |
| 青 | `#1237C4` |
| マゼンタ | `#E600C7` |
| 赤 | `#E53935` |
| フォント | `fontFamily: 2` のサンセリフ系 |
| 通常文字サイズ | `max(28, 60 × S)` |
| 小文字サイズ | `max(24, 48 × S)` |
| 内側余白 | `max(20, 38 × S)` |
| 顔からの距離 | `max(24, 40 × S)` |
| 動画端の安全領域 | 左右5%、上下5% |

差し色は1つの吹き出しで原則1色、最大2色まで。色付き文字は本文全体の40%以下を目安にする。通常会話を全文赤にしない。

## プリセット

### A. 通常会話

- 形: 縦長楕円
- 幅: `260〜420 × S`
- 高さ: `420〜720 × S`
- 列数: 1〜3列
- 1列: 6〜12文字を目安
- 尻尾: 長さ `70〜150 × S`、根元幅 `35〜75 × S`
- 用途: 大半の会話

長い文章は文字を小さくする前に2つへ分割する。4列以上が必要なら分割対象。

### B. 短い返答

- 形: 円または短い楕円
- 幅: `140〜240 × S`
- 高さ: `140〜280 × S`
- 文字: 1〜5文字、`max(34, 72 × S)`
- 用途: 「え？」「は？」「はい」など

### C. 感情バースト

- 形: 白い楕円の外側へ12〜20本の短い放射線を置く
- 幅: `180〜320 × S`
- 高さ: `180〜420 × S`
- 線: 黒、`max(2, 3 × S)`
- 文字: 赤または黒、`max(34, 72 × S)`
- 用途: 驚き、強い決意、短い叫び

1シーンで1つまで。長文には使わない。

### D. 心の声

- 形: 白い楕円
- 尻尾: 発話者へ向かって小さな白い楕円を2〜3個並べる
- 文字: 黒。必要なら青を少量
- 用途: 明示的な内心のみ

参照動画では通常会話が中心なので、台本に内心指定がない限り使わない。

### E. ナレーション帯

- 形: 白い縦長長方形。角丸は弱く、尻尾なし
- 幅: `130〜280 × S`
- 高さ: 必要な文字数に合わせる
- 輪郭: なし、または `#D9D9D9` で1〜2px
- 文字: `max(24, 52 × S)`
- 用途: 場面説明、導入、時間経過

黒を主色にして、出来事や感情のキーワードだけ赤・青・マゼンタにする。

## 縦書きルール

Excalidrawの編集可能テキストで縦書きを再現するため、1文字ごとに改行する。

例: `よろしく` → `よ\nろ\nし\nく`

- 複数列は右列から左列へ並べる
- 句読点だけを次列の先頭に送らない
- 名前、数値、英字を途中で分断しない。必要なら短い横書きの別要素にする
- 1つの色単位を1つの `text` 要素にする
- 明示的な `width` と `height` を指定する。高さは概算で `文字数 × fontSize × lineHeight`
- `lineHeight` は1.0〜1.12を使い、縦方向の間延びを防ぐ
- テキスト要素の `autoResize` は `false` にし、計画した枠を維持する

## レイヤー順

要素配列は次の順で作る。

1. 尻尾または心の声の小円
2. 吹き出し本体
3. 通常文字
4. 差し色文字
5. 感情バーストの放射線

尻尾を先に置くと、本体との継ぎ目を楕円が隠せる。

## IDとグループ

例:

- group: `r3-s02-aiko`
- `r3-s02-aiko-tail`
- `r3-s02-aiko-body`
- `r3-s02-aiko-text-01`
- `r3-s02-aiko-accent-01`

各要素の `customData` 例:

```json
{
  "buzzassistSpeechBubble": "r3",
  "sceneId": "s02",
  "speakerId": "aiko",
  "bubbleRole": "body"
}
```

## 配置優先順位

空き領域が競合するときは、次の順で守る。

1. 顔と口を隠さない
2. 発話者が分かる
3. 読み順が自然
4. 文字サイズを維持する
5. 吹き出し形状を完全な楕円に保つ

楕円を少し細くするより、顔を隠す方が悪い。どうしても入らない場合は、別パネルや画像外へ置かず、セリフを2つへ分割する。

## 完了判定

- 100%表示で本文が読める
- 50%表示でも話者と読む順番が分かる
- 各吹き出しを選択すると、本体・尻尾・文字が一緒に動く
- 既存の漫画画像や手動要素が消えていない
- 強調色を外しても意味が通る
- 吹き出しの外へ文字が出ていない
- 画面端から5%以内に重要文字がない
