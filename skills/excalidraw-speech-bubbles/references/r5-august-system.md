# R5 漫画吹き出し・8月納品仕様

## 参考動画から採用するもの

漫画本編では、吹き出しは派手な装飾物ではなく可読性のための器として扱う。通常は縦長の滑らかな白楕円、細めの黒輪郭、明朝系の縦組み、中央に寄り過ぎない均等な余白。尻尾は常用せず、話者が曖昧なカットだけ短く付ける。

2026-08-02に2本の参考動画本編を全尺ダウンロードして時間分散サンプリングし、ブラウザ上の実フレームでも再確認した値を `reference-video-locked-v3` に固定した。通常会話はおおむね画面幅12〜19%、画面高36〜72%、輪郭は1280×720換算で約2.6〜3px、本文は画面高の約4.6%を基準とし、4.3%未満へ縮小しない。1〜5文字の短い返答だけは幅5.5〜9.5%、画面高14〜30%まで小さくする。通常会話は1〜3列に制限し、既定色は黒一色、赤強調は明示指定された場合だけ使う。

台本側の改行は列数の強制指定にしない。過剰な改行を除去して、禁則を守りながら1〜3列へ再配置する。列を固定する必要がある特殊ケースだけ `columns` を使い、4列以上なら別の吹き出しへ分割する。

サムネイルの極太文字・色付き訴求は別プロファイルに分離し、8月版の本編プロファイルへは混ぜない。

## アーキテクチャ

```text
台本・カット表
  ↓ 話者位置 / 顔領域 / 向き
bubble spec JSON
  ↓ 配置と4プリセット
決定論的SVG renderer
  ↓ 透明な画像同寸オーバーレイ
Excalidraw
  ↓ 選択時サイドパネル
角度・長さ・種類を再生成
```

GPT-Image-2はデザイン探索や将来のクロマキー素材候補に限定する。毎回の吹き出し生成には使わない。背景透過の最終物はブラウザSVGそのものなので、クロマキー誤差も画像生成待ちもない。

## 4プリセット

| ID | 用途 | 形 | 尻尾 |
| --- | --- | --- | --- |
| dialogue | 通常会話 | 滑らかな縦長楕円 | 既定なし、必要時のみ短い単一パス |
| shout | 怒鳴り・強い叫び | dialogueと同じ滑らかな縦長楕円 | 既定なし |
| thought | 心の声 | dialogueと同じ滑らかな縦長楕円 | 既定なし |
| narration | 語り | 四角い白枠 | なし |

プリセット追加はプロファイルJSONとレンダラー分岐で行えるが、8月版では増やさない。

## 話者アンカー

顔検出モデルは使わない。上流のカット表から次を流す。

- `position`: left / center / right
- `faceBand`: upper / middle / lower
- `facing`: left / right / front
- `faceBounds`: 分かる場合の顔矩形

`faceBounds` がある場合は口元相当の高さ69%をアンカーにする。なければ位置と帯から既定アンカーを計算する。外れた場合は、サイドパネルで尻尾角度と長さを変える。

配置は話者と同じ側を第一候補にしない。話者の反対側にある外側余白、次に人物間の空白を優先する。上〜中央を先に試し、手や小道具を隠しやすい下端配置は最後の候補にする。`placementSide` が明示された場合だけその側を優先する。

## 日本語組版 v1

- ブラウザのSVG `writing-mode="vertical-rl"` を使う。
- 同梱プロファイルのフォント順: Hiragino Mincho ProN、Yu Mincho、Noto Serif JP、serif。
- `@font-face` を追加する場合もWebフォントとして同梱し、OSネイティブモジュールを増やさない。
- `vert` / `vrt2` を有効にする。
- `text-orientation="upright"` を使い、半角数字を全角へ変換して1字ずつ直立させる。
- `...` / `…` / `⋯` は縦三点リーダー `︙` へ正規化する。
- 行頭の句読点・閉じ括弧・小書き文字、行末の開き括弧だけ基本禁則を行う。
- 縦中横、完全禁則、文字の全面パス化は9月以降。

書き出しは既存ChromiumのSVG/Excalidraw `exportToBlob` 経路へ一本化する。サーバー側のSharp/librsvgは導入しない。

## 単一パス尻尾

楕円上の接続点を2つ取り、その間の楕円弧を尻尾の2本の二次ベジェへ置換する。塗りと輪郭は1本の閉じたパスなので、根元の横線や別部品感が出ない。

`reference-video-locked-v3` の最大長は次の最小値。

- 画像幅2.5%
- 本体幅16%
- 本体高8%

顔・口の保護領域へ入る直前で止める。先端を口へ接触させない。

## 配布要件

- Sharp、fontkitなどプラットフォーム別バイナリを依存へ追加しない。
- `npm install` / セットアップスクリプト / Codexプラグイン自動更新を壊さない。
- SVGが主経路。PNGが必要な場合はブラウザCanvas `toBlob()` を使う。
- 将来のGPTクロマキーは補助機能かつブラウザCanvasの外周flood除去で実装する。

## 品質ゲート

- overflowなし、画面高4.3%以上、3列以下、`textLoss: false`。
- 顔・口との重なり0.5%以下。
- 手・証拠・小道具との重なり10%以下。
- 本体面積が画面26%以下。
- 尻尾長が画面幅6%以下。
- 100%表示で輪郭と字面が自然。
- 50%表示でも本文と話者が判断できる。
- プラグイン新規インストールが一発で成功する。
