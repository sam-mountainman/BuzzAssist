# 漫画人物キャラ台帳・実案件テスト

BuzzAssist R1 の「台本 → 新キャラ抽出 → 各3案 → 人が採用 → 表情・角度シート → 1人/2人/3人カット」を、漫画系の人物で検証するためのテスト一式です。

## 登場人物

- 田中 悠斗: この動画専用。28歳、黒髪で冴えない若手会社員。
- 黒川 部長: この動画専用。45歳、威圧感のある上司。
- 佐藤 誠司: チャンネル共通。55歳、穏やかだが芯のある助っ人。

## 合格条件

1. 台本から3名だけが登場人物として抽出される。
2. 新キャラごとに、同じ要件を守りながら見分けやすい3案がキャンバスへ並ぶ。
3. 採用前の候補は `canvas/characters.json` に登録されない。
4. 採用後、設定画と表情・顔角度シートの2枚だけがキャラ台帳へ登録される。
5. 1人、2人、3人の各カットで、顔・髪型・服・年齢・体格が混ざらない。
6. 全10カットで画風、オフィス、人物の見た目が継続する。

## ファイル

- `test-case.json`: キャラ設計、画風、生成数などの入力値
- `script.txt`: 登場人物抽出に渡す台本
- `scenes.json`: 採用後に生成する全10カット

候補の採用は人が行います。候補を自動採用して本編へ進めるテストではありません。
