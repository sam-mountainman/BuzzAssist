# 参考台本と制作への反映方針

参考台本の**原文はこの公開リポジトリに置きません**。ユーザー提供の逐語原文で、文字起こし由来のものを含むため、
共有される配布物へ入れるべきものではありませんでした。原文は運営者の手元（Channel Pack 側）にあります。

ハーネスが実際に使うのは下の**構造と感情曲線**だけで、原文の文章・固有名詞・具体的な事件や会話は
もともと複製しない方針でした。つまり原文が公開物に無くても、制作に必要なものは何も失われません。

## 参考にする物語の型

1. 価値観を短い比喩で提示する、詩的な冒頭ナレーション
2. 接客・家事・仕事など、主人公の誠実さが行動で分かる日常
3. 再会や共同生活を通した、安心できる関係の積み上げ
4. 約束・信用・居場所を軽視する人物との価値観の衝突
5. 序盤の小道具や過去が、終盤の証拠・告白として反転する構成
6. 相手を打ち負かす場面だけで終わらず、静かな恋愛の余韻で閉じる

制作動画では、この構造と感情曲線だけを参考にします。参考台本の文章、固有名詞、具体的な事件や会話は複製しません。
