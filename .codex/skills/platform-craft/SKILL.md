# Codex用アダプター

共通技法に関わる作業を始める前に、`../../../.agents/skills/platform-craft/SKILL.md`
を最後まで読み、共通正本として厳守する。課金APIの再送規則、入口の fail-closed
ルーティング、RunReceipt の不変条件、この層で繰り返し見つかった不具合の型は
すべてそちらにある。既存実装をコピーして2つ目の家を作らないこと。
